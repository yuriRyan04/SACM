# SACM — Sistema de Auxílio e Controle de Monitoria

O **SACM (Sistema de Auxílio e Controle de Monitoria)** é uma aplicação web desenvolvida como projeto acadêmico no Centro Estadual de Educação Profissional Professora Lourdinha Guerra (CEEP-PLG), localizado em Parnamirim/RN.

O sistema tem como objetivo facilitar a organização e o acompanhamento das atividades de monitoria escolar, aproximando alunos, professores e equipe gestora por meio de uma plataforma digital.

## Funcionalidades

- Cadastro e gerenciamento de monitores.
- Consulta de disciplinas e horários de monitoria.
- Agendamento de atendimentos pelos alunos.
- Gerenciamento de disciplinas vinculadas aos professores.
- Controle administrativo das monitorias.
- Emissão de certificados para monitores.
- Instalação como aplicativo por meio da tecnologia PWA.
- Acesso às funcionalidades conforme o perfil do usuário.

## Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e identidade visual.
- **JavaScript:** interatividade e funcionalidades do sistema.
- **PHP:** processamento e comunicação com o banco de dados.
- **MySQL:** armazenamento das informações.
- **PWA (Progressive Web App):** recursos de instalação e funcionamento offline.

## Organização do sistema

O SACM possui três perfis principais de acesso:

- **Aluno:** consulta monitorias e realiza agendamentos.
- **Professor:** acompanha as funcionalidades relacionadas às disciplinas e monitorias sob sua responsabilidade.
- **Gestão:** administra os cadastros e as informações gerais das monitorias.

## Objetivo do projeto

O projeto busca contribuir para a organização das atividades de monitoria, facilitando o acesso dos estudantes às informações e auxiliando a instituição no gerenciamento dessas atividades.

## Segurança

As credenciais de acesso ao banco de dados e as configurações de autenticação institucional não fazem parte deste repositório público.

**Instituição:** Centro Estadual de Educação Profissional Professora Lourdinha Guerra.
